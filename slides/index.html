AIML Interactive Demos

AIML 2003 (NLP) • AIML 2013 (Computer Vision) — Rose State College, Spring 2026

Inside the Pipeline: TF-IDF + Logistic Regression

Trace a movie review through every step — tokenization, TF-IDF vectorization, the dot product, and sigmoid classification. Type your own text to see how the model processes it.

 Logistic Regression: The Binary Classifier

Drag a decision boundary, watch gradient descent train in real time, inspect individual predictions, and see where the model fails. The plot uses two features, so you can see the whole decision boundary at once.

 Cosine Similarity: Measuring How Alike Two Things Are

Drag 2D vectors to build geometric intuition, compare documents by their words, compare images by their edges, and explore similarity matrices. The same formula works for text in NLP and for images in CV.

 A Token Is a Token: How Words and Pixels Both Become Vectors

Split a sentence into WordPiece tokens and an image into patches side by side, inspect the real 384-value embedding row for each token and the raw pixel values for each patch, then compare the two sequences of vectors a transformer receives.

 What Do Embeddings Encode?

An embedding model converts each word into a list of numbers that encodes the word's meaning. Set attribute values, find the nearest word by cosine similarity, compute analogies such as king − man + woman, and compare toy vectors with real 384-dimension embeddings.

 Pixel Histograms: How Machines Represent Light

Load an image and watch its histogram update as you switch modes. Compare grayscale conversion, thresholding, downsampling, equalization, and single-channel views to see how each one changes the pixel values a model receives.

 HOG: Histogram of Oriented Gradients

Watch an image become a vector one step at a time. The page converts it to grayscale, computes Sobel gradients, builds a histogram for each cell, draws the HOG visualization, and compares two descriptors with cosine similarity, all in your browser. You can upload your own images.

 Confusion Matrix: Measuring What a Classifier Gets Wrong

Accuracy summarizes a classifier in one number, and the confusion matrix breaks that number down by true label and predicted label. Edit the cell counts and watch precision and recall change. A classifier can score high accuracy on an imbalanced dataset and still never predict the rare class.

 Neural Networks: Why Layers Matter

A single neuron can only separate classes with a straight line. With a hidden layer, a network can separate data that no straight line can. Train the network in your browser and watch the decision boundary curve as training runs, then inspect what each hidden unit computes.

 Attention: How Every Word Reaches Across the Sentence

Click a word to see its attention weights over the other words. Step through the Q/K/V computation and compare attention heads. Swapping one adjective changes the attention weights across the whole sentence. Transformers are built from this mechanism.

 Hallucination: Why Models Produce Fluent Falsehoods

A language model has no store of facts. It predicts the next token from the tokens before it, so it can produce a fluent sentence that is false. Step through generation one token at a time and adjust the temperature to see how a wrong token can become the one that is sampled.
