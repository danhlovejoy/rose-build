Module 1: Prompt Engineering

1. What is the difference between a prompt and a context window?

A prompt is the text you send to the model. The context window is the maximum number of tokens the model can process in a single call — your prompt plus the model’s response must fit inside it. Gemini 1.5 Pro has a context window of roughly 1 million tokens; GPT-4 Turbo has 128k. If your prompt exceeds the window, the model either truncates or errors out.

2. Why does few-shot prompting often outperform zero-shot on structured tasks?

Few-shot examples demonstrate the expected output format, tone, and reasoning pattern. Without them, the model infers format from its training distribution, which may not match what you want. The examples act as implicit constraints — they narrow the space of plausible outputs without modifying the model’s weights.

Module 2: TF-IDF & Text Classification

3. What does TF-IDF measure, and why is the IDF term necessary?

TF (term frequency) counts how often a word appears in a document. IDF (inverse document frequency) penalizes words that appear in many documents. Without IDF, common words like “the” or “is” would dominate the vector because they’re frequent everywhere. IDF ensures that words distinctive to a document receive higher weight.

4. A TF-IDF vector for a document has 50,000 dimensions. Most values are zero. Why?

Each dimension corresponds to one word in the vocabulary. A single document uses only a small fraction of the full vocabulary, so most dimensions get a TF of zero. This is called a sparse vector — high-dimensional but mostly empty. Sparse representations are memory-efficient but cannot capture synonymy (different words, same meaning get orthogonal vectors).

5. You trained a logistic regression classifier on TF-IDF features and it gets 92% accuracy on positive reviews but 61% on negative reviews. What likely went wrong?

Class imbalance. The training set probably contained far more positive reviews than negative ones, so the model learned to default toward “positive.” Fixes include resampling (over-sample negatives or under-sample positives), adjusting class weights in the model, or collecting more negative examples.

Module 3: Learned Embeddings

6. What does cosine similarity measure, and why is it preferred over Euclidean distance for comparing embeddings?

Cosine similarity measures the angle between two vectors, ignoring their magnitude. Two sentences with the same meaning but different lengths get similar embeddings that point in the same direction but may differ in magnitude. Euclidean distance penalizes magnitude differences, which makes it sensitive to sentence length rather than meaning. Cosine strips that out.

7. How is a sentence embedding fundamentally different from a TF-IDF vector?

A TF-IDF vector is sparse, high-dimensional, and based on exact word counts. It cannot represent synonymy (“happy” and “joyful” get orthogonal vectors) or word order (“dog bites man” equals “man bites dog”). A sentence embedding is dense (384 or 768 dimensions, all non-zero), produced by a neural network that was trained on millions of sentence pairs, and encodes meaning, word order, and context into the vector geometry.

8. What is t-SNE, and why can’t you use it to measure precise distances between points?

t-SNE is a dimensionality reduction algorithm that maps high-dimensional vectors into 2D or 3D for visualization. It preserves local neighborhood structure (nearby points stay nearby) but distorts global distances and cluster sizes. Two clusters that appear far apart in a t-SNE plot may actually be close in the original space. Use it for qualitative exploration, not quantitative measurement.

Module 4: Attention & RAG

9. Explain Query, Key, and Value in one sentence each.

Query: the vector a word uses to ask “what should I attend to?”

Key: the vector a word uses to advertise “here’s what I contain.”

Value: the vector that actually gets passed to the output once a word wins attention.

The dot product of Query and Key determines the attention score; the Value is what flows through once that score is high.

10. Why do transformers use multiple attention heads instead of one?

A single head can only track one type of relationship at a time. Multiple heads run in parallel, each learning a different pattern: one might track coreference (pronouns → nouns), another syntax (verbs → modifiers), another local context (neighboring words). Their outputs are concatenated to produce a representation that encodes many relationship types simultaneously.

11. What is the difference between RAG and fine-tuning?

Fine-tuning changes the model’s weights permanently by training on new data. The knowledge becomes part of the model but is frozen at training time. RAG leaves the model untouched and injects relevant documents into the prompt at query time. RAG can answer questions about documents that didn’t exist when the model was trained, and updating the knowledge base requires no retraining — just adding new documents to the vector store.

12. Your RAG pipeline retrieves 3 chunks from a document and passes them to Gemini. Gemini produces a confident but wrong answer. Name two possible failure points.

Retrieval failure: the 3 chunks may not contain the answer. The retriever matched on surface similarity rather than semantic relevance, or the correct information was split across chunk boundaries.

Generation failure: the chunks contain the answer but the model hallucinated anyway — it generated a response from its parametric knowledge rather than grounding in the provided context. This is an extrinsic hallucination.

Other valid answers: chunk size too large (relevant passage diluted by noise), embedding model encoded the query differently than the document text, or the question requires reasoning across chunks that the model fails to perform.
