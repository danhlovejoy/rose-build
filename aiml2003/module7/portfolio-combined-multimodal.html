AIML 2003 (NLP) + AIML 2013 (CV)

Dual-enrollment portfolio: AIML 2003 + AIML 2013

This combined portfolio is for students enrolled in both courses. You create one project and give one presentation covering both NLP and CV. It replaces both individual portfolio presentations. If you're enrolled in only one course, use that course's standalone portfolio assignment instead.

You'll design your own project that connects NLP and CV. The project should demonstrate at least two Course Learning Outcomes from each course. During Tuesday's class, we'll use an app I built in Hugging Face Spaces to generate a custom assignment sheet and rubric tailored to your specific project.

Your code goes in your GitHub repo. You'll present it live in class.

Course Learning Outcomes

Your project must demonstrate at least two outcomes from each course. You'll identify which ones apply to your project when we build your custom assignment sheet on Tuesday.

AIML 2003 — Natural Language Processing

  1. Manipulate text as numerical data by explaining the process of tokenization and the creation of word embeddings.
  2. Engineer effective prompts using structured techniques (few-shot, chain-of-thought) to control LLM output behavior and format.
  3. Implement core NLP tasks including classification, summarization, and sentiment analysis using hosted LLM APIs.
  4. Construct a Retrieval-Augmented Generation (RAG) pipeline that connects an LLM to an external knowledge base.
  5. Orchestrate simple AI agents that utilize basic tools (like a calculator or search) to complete multi-step tasks.
  6. Evaluate LLM performance by identifying hallucinations and applying frameworks for bias and safety auditing.

AIML 2013 — Computer Vision

  1. Represent and transform digital images as multidimensional NumPy arrays to perform image manipulation of any kind.*
  2. Apply spatial filters and kernels to extract low-level features like edges and textures from raw image data.
  3. Deploy pre-trained deep learning models (such as ResNet or YOLO) to perform image classification and real-time object detection.
  4. Calculate and interpret model metrics including accuracy, precision, and recall, using confusion matrices to identify specific failure modes.
  5. Implement visual similarity search by extracting feature vectors (embeddings) from images and calculating distance in a vector space.
  6. Audit vision systems for demographic bias, proposing mitigation strategies for ethical issues in facial recognition and surveillance.

*The syllabus wording for this outcome is "...to perform cropping, scaling, and color-space shifts." It has been broadened here so you can demonstrate image manipulation techniques from any point in the course, not just the introductory operations from Module 1.

Proposal (Thursday Lab, May 7)

Bring a draft proposal to Thursday lab. We'll review it together and finalize your plan. The proposal covers four things:

  1. Project title and one-sentence summary.
  2. At least two CLOs from each course your project demonstrates, with one sentence each explaining how they appear in your work.
  3. Data and tools — datasets, APIs, models, libraries.
  4. Presentation format — Colab notebook walkthrough, Gradio app demo, or something else you have in mind.

Presentation (Tuesday, May 12) Presentation

Eight to ten minutes, live. You can walk through a Colab notebook, demo a Gradio app on Hugging Face Spaces, or run your code in any other environment — as long as the audience sees it execute live. Cover the problem you're solving, the approach you took, what your results show, and what you'd do differently with more time. The presentation counts toward both courses.

Your code goes in your GitHub repo. Submit the same repo link to both Canvas courses.
