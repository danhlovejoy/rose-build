Module 4: Basic RAG

AIML 2003 • Introduction to Natural Language Processing • Spring 2026

Last week your search engine found the right sentences but couldn't explain them. This week you close the loop: retrieve the relevant passages, hand them to an LLM, and generate an answer grounded in a document the model has never seen.

This Week's Focus

Investigate a working Retrieval-Augmented Generation pipeline: run a pre-built system that loads a PDF, chunks it, embeds the chunks with Nomic Embed, stores them in ChromaDB, retrieves context for a question, and generates an answer with Gemini. Then probe how the vector space works through hands-on experiments.

What's in This Module

  1. Readings & Prep: A conceptual introduction to the attention mechanism (3Blue1Brown), the RAG architecture pattern, the ChromaDB quickstart, and a short reading on chunking strategies. Together, these explain why transformers work, how RAG uses retrieval to ground generation, and how to set up the vector database you'll use in the lab.
  2. Module 4 Lab: Investigating the RAG Pipeline. A pre-built RAG system handles PDF extraction, chunking, embedding, ChromaDB storage, and Gemini-powered answer generation. You run the system, then investigate it through four experiments on embedding similarity, vector arithmetic, cross-modal bridging, and chunking strategies.
  3. Combined Lab: Investigating the Universal Search Engine. For dual-enrolled students taking both NLP and CV. A pre-built search engine backed by ChromaDB indexes both text chunks and images. You run the system, then investigate it through five experiments on embedding similarity, vector arithmetic, cross-modal bridging, and chunking strategies.
  4. Assignment Sheet: Deliverable details, abbreviated rubrics with Canvas links, and the due date for Tuesday, April 21.
  5. Ethics Discussion: This week's ethics prompt on who controls the context in a RAG system and what gets left out.
