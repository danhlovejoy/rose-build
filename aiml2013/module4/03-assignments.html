Deliverable 1: Module 4 Lab Lab

Overview

In the readings and in class, you learned how pre-trained CNNs serve as feature extractors: remove the classification head, feed in an image, and the remaining layers produce a dense embedding that encodes visual content. This lab gives you a working image retrieval system — MobileNetV2 embedding extraction, ChromaDB storage, and similarity search with visualization — and asks you to investigate how it works. You run the system in Part 1, then probe the visual vector space through four experiments: the similarity game, embedding surgery, the caption bridge, and a retrieval quality deep dive.

The markdown cells you write after each experiment are the core of this lab. They’re where you explain what you observed, what surprised you, and what it means. Those reflections are also the substance of your demo.

What to Submit

  • A completed Colab notebook (.ipynb) saved to your GitHub repo at module4/lab4-cv-investigation.ipynb.
  • All cells executed with visible outputs (don’t clear outputs).
  • Markdown reflection cells completed for every experiment.
  • No API keys or secrets anywhere in the notebook.
  • Submit the GitHub link in Canvas. If it’s not in the repo, it doesn’t exist for grading.
Start this in Thursday lab. We’ll run through Part 1 together and start the experiments. Come with the readings done so you know what vector databases and feature extraction are before we investigate one.

Deliverable 2: Module 4 Demo Demo

Overview

A three- to five-minute live demo during Tuesday’s class (April 21, 7:00 PM). Your notebook is your demo — no separate slides required. Walk the class through one experiment in depth, show a retrieval failure, demonstrate the caption bridge, and share what you learned.

What to Cover

  1. One experiment in depth: Pick the experiment that surprised you most. Show the code, show the output, and explain what you learned. This is the centerpiece.
  2. A failure: Show an image where the retrieval system returned the wrong class. Explain what visual feature fooled the model.
  3. The caption bridge: Show one text query that found the right image and one that didn’t. What does this tell you about the gap between visual similarity and language?
  4. One sentence you couldn’t have said before this lab: What do you now understand about embeddings or vector search that you didn’t before?

Format

Share your screen and run your notebook live. If you attend via Zoom, have your notebook open and ready to run before your turn.
